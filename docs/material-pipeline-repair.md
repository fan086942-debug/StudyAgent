# 资料学习流程修复与统一工作台

日期：2026-10-21。

本次按通用流程修复资料检索、引用问答、整份总结与生成校验；生产代码没有写入具体书名、学科主题、答案或页码。用户文件仅用于复现，其内容和模型输出保存在已忽略的本地 `data/` 目录。

## 流程

1. 上传资料保留真实页码、幻灯片或段落位置。减少单块内大量重复行，避免水印占据主要检索特征与模型输入。
2. 按选定课程和资料范围检索。保留原向量搜索接口；学习问答增加关键词检索，用低频、具体的关键词优先定位正文，处理带章节背景的复合问题及文字换行。
3. 按主题生成时，识别编号章节的范围并展开正文，跳过反复出现的总目录，在下一个同级标题处停止。没有编号的 Word 等资料使用解析器已经保存的标题层级和正文范围。
4. LLM 接收检索出的原文及来源编号，生成概括、重点、易错点、题目或参考解答。回答保留实际引用；依据不足时仍允许明确标注的模型推理解答，不伪造引用。
5. 生成结果同时检查结构、主题、题数、题型、难度、重复题和来源编号。结构或任务格式错误合计最多纠正一次；拒答、缺少依据和输出截断不会触发这种重试。校验仍失败时停止并说明具体原因，不保存不合法成品。
6. 整份学习只缓存通过校验的小节，重试可继续使用。旧索引的重复噪声也会在发送给模型前清理，不改写原文快照与缓存键，不要求用户为此重新上传。

## 用户界面

- 学习工作台统一承载资料问答、知识点总结、复习提纲、重点与易错点、模拟练习、原文依据和结果预览。
- 移除独立“复习与生成”导航；留下学习工作台、历史题库、错题与计划、对话记录四项。
- 题型和数量作为可展开设置，生成历史作为可展开记录；原生成表单、保存、练习、来源与下载能力保留。
- 旧 `#generation` 链接兼容跳转到工作台，并展开设置。
- 移除侧栏指定宣传语。

## 验证

先使用线上提交 `ee48b9b` 的隔离源代码副本复现：主题生成返回无依据、复合问题仅有模型推理且无引用、整份总结两次结构校验失败。

修复后同一用户资料的三个真实 DeepSeek 场景全部通过：主题概括包含重点与易错点；问答返回原文引用；整份资料总结成功保存并可下载，覆盖 157 个正文片段。验收在独立数据目录运行，没有修改线上资料。

通用回归覆盖两组不同主题 × PDF/PPTX/DOCX，目录与正文范围、复合问句、原文引用信息、过期资料隔离、未通过来源校验时拒绝保存、一次纠正与计费 usage 汇总、有效缓存复用、无编号 Word 标题及旧索引噪声处理。完整回归已通过 269 项；此后增加的旧索引兼容和无编号标题测试分别通过针对性复测，最后一次相关生成回归 51 项及补充回归 14 项通过。Ruff 与 JavaScript 语法检查通过。

真实 Edge 浏览器验收通过：四项导航、工作台内对话出题、设置生成、记录、原文入口、旧链接兼容、宣传语移除；1440px 桌面与 390px/320px 手机布局无横向溢出，JavaScript 错误为零。

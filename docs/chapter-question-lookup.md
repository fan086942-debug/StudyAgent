# 章节题号引用

支持将“第四章第6个题目”“第4章第六题”“第四章的第六道题”等请求作为 `4.6` 的查找候选。先在当前课程和所选文件内查找真实原题，再调用解题模型；不会仅凭题号生成题干。

- 试卷：按完整题号查已解析题库，再将真实题干、原图及来源交给解题工具。
- 教材、课件及笔记：直接查已完成处理的正文题号，支持半角和全角小数点，不依赖语义相似度阈值。
- 多份文件匹配同一题号时，要求勾选具体文件；缺少上传、处理未完成和未找到原题分别给出明确提示。
- 章节解答请求在首轮先执行定位和解题，避免规划模型未查资料就要求用户重输题干。普通概念问答仍可直接调用模型。

当前规则查找原文中的 `4.6` 这种完整题号；不会将“第四章的第六道题”任意解释为某页的第六个段落。各章重新从 `1` 编号的文件仍需要进一步结合章节结构定位。

验收：全套测试 260 项通过；对用户原《操作系统》作业手册分别按试卷和教材上传，首次提问“第四章第6个题目解答”，真实 DeepSeek 均定位并解答分页与分段存储管理比较，原题位置为 PDF 物理第 7 页。私人题干、回答与 API 配置仅保存在本地忽略目录，未提交到仓库。

# 通用资料学习与代码审计（2026-10-12）

学习流程为：上传参考资料 → 提取知识点与总结 → 根据资料生成复习卷，或关联已上传试卷 → 对照教材依据练习 → 自评与错题复习。流程与教材名称和学科无关。

## 实现与入口

| 操作 | 前端入口 | 服务端 |
|---|---|---|
| 提取、总结知识点 | 资料旁「总结知识点」；整份资料总结选项；自然语言 Agent | `POST /api/study`，`include_questions=false` |
| 根据资料出卷 | 整份资料学习包；「根据 PPT 出题」等请求 | `POST /api/study`，`include_questions=true` |
| 查看保存的知识 | 复习与生成中的知识点总览 | `GET /api/courses/{id}/material-knowledge` |
| 资料找题 | 资料旁「找关联试题」；总结小节历史题按钮 | `POST /api/courses/{id}/material-question-links` |
| 试题找资料 | 题库中的「定位教材 / 课件依据」 | 同一关联接口，`direction=exam_to_material`、`question_id` |

关联接口的 `document_ids` 限定参考资料，`exam_document_ids` 限定试卷；`material_id` 聚焦具体文件，`chunk_ids` 聚焦总结的依据，`artifact_id` 校验总结是否仍有效。各 ID 都由课程和范围校验保护。Agent 请求中的资料范围同时约束两侧，不允许模型扩大范围。

知识点来自保存在学习包中的总结、重点与易错点，每项保留来源快照。总览读取保存结果而非自动发起模型生成。当前有效性除 ready 状态和 Embedding 配置外，还核对分块正文与位置，因为旧分块 ID 在重建时可能被复用。历史记录保留，失效依据不参与当前知识总览或总结关联。

现有试卷关联优先匹配题目标注的知识点与资料实际正文，未命中标签时以英文词和中文相邻字的正文重合寻找候选。题目只关联真实资料片段，卡片显示标签匹配或文本相似；分数用于排序，不是正确率。模型解题另走分析入口，不把关联或历史题干当作参考答案。未发现关联、尚无已解析试卷、尚无可用参考资料分别返回具体提示。复杂同义表述、数学公式与图片语义仍可能漏匹配。

生成卷的每题另有「查看这题的教材 / 课件依据」，直接展开该题生成时保存的引用原文；历史试卷使用实时关联入口。两种入口都能从题目回到资料阅读。

## 删除、合并和修正的代码

| 审计结果 | 已实施处理 | 原因 |
|---|---|---|
| 自然语言路由只覆盖整书/章节/卷子，PPT/Word 单纯知识总结可能误入问答 | 将判断集中到 `app/agent/intents.py`，生成入口和工具授权使用同一定义；增加总结、提炼、出题、否定出题判断 | 消除文件名/章节表达依赖和路由冲突 |
| 检索与整份资料学习各自拼装 Source | 删除两套重复拼装，改为 `app/rag/sources.py` | 保持来源、PDF 页链接、幻灯片和文档位置一致 |
| 问答、生成结果和关联弹窗重复渲染来源卡片 | 统一为前端 `sourceCard` | 同一位置格式；长原文按需展开 |
| 题目分析将多个知识点用空格拼成一个查询 | 改为优先复用双向关联，必要时逐知识点检索并去重；相关题逐知识点标签查找 | 避免将多个知识点误要求同时连续出现 |
| Prompt 要求所有生成先补充主题 | 明确指定主题生成和整份资料学习的区别 | 整份资料无需额外题号或主题 |
| Word 章节只认 Heading 样式，PDF 只认一种中文标题格式 | 共用保守标题规则，支持无样式中文章节、编号小节和 Chapter 标题 | 不依赖特定书籍的目录写法 |
| 长 PPT 每页有标题，会触发 64 小节限制 | 连续小节合并组织总结，仍逐段读取全部正文，并保存子标题覆盖统计 | 避免资料结构数量成为无意义失败原因 |
| 重建后旧 ID 可让历史摘要重新被视为有效 | 校验正文及位置；总结关联也验证来源快照 | 防止过期知识混入当前资料 |

保留原有主题生成、关键词题库、问答、OCR、上传取消和历史 API，这些入口仍有对应职责与回归测试。没有按名称批量删除 Agent、脚本、测试或用户资料。新增功能复用现有正文与学习包存储，没有另外建立易失效的重复知识库表。

## 验证与边界

`tests/test_material_learning.py` 包含 PDF/PPTX/DOCX 关联、通用总结意图、双向来源、资料/试卷分开限定、跨课程拒绝、无标签题匹配、无历史卷提示、保存总结、删除/重建失效、同 ID 正文变化，以及 80 页课件全量读取验证。`scripts/browser_material_learning.cjs` 在独立的 8767 服务和合成资料上验收总结、知识总览、双向入口、位置、练习导航、390px 布局与减少动画偏好。结果见 [浏览器验收](evaluation-material-learning-ui.json)。原学习包生成和导出另通过 `scripts/browser_study.cjs` 回归。

工程测试与合成资料不能证明真实模型的每项总结或教材考点关联都准确。真实总结和出题使用已配置的 API，离线模式明确显示原文摘录；复杂 OCR 公式仍需核查。支持 PDF、PPTX、DOCX；旧 PPT/DOC 应转换格式，纯图片课件/Word 未实现自动图片 OCR。长资料仍受上传、文字量和生成调用预算约束，超限有明确提示。

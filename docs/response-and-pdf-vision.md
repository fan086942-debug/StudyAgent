# 首轮解答与 PDF 原图

## 行为

先检索当前课程和所选资料。资料足以支持回答时返回资料答案；检索不足时，在同一次请求内调用解题模型，输出带标识的模型参考解答。已找到唯一历史试题时使用完整原题分析，不把题号当成题干。同号题存在歧义时仍需选择具体题目。

模型有时会把正确引用放进 citation_ids，却漏写正文中的 [S1] 标记。这种格式遗漏现在由后端补齐：只使用模型已经声明、且确实属于当前检索结果的编号。未知编号、互相冲突的编号、模型编造的位置仍会拒绝展示。没有声明任何引用的回答标为模型推理解答。

## PDF 图表

除了用于检索的文字/OCR，解题时还会按真实页码渲染相关 PDF 原页，并作为图像发送给支持视觉的模型。题目原图和参考资料原图分别说明用途；参考原图与已检索编号对应，来源卡片继续显示解析器记录的页码。

作业 PDF 按教材类别上传时，可以根据“第 1.1 题”这类完整题号精确定位，不要求先改为试卷类别，也不依赖该短查询达到向量相似度阈值。

默认每次最多读取 3 页，每页长边最多 2000 像素；按需渲染，不为整本资料预先调用视觉模型。过多页面、原图读取失败或模型不支持图像时会给出提示。清晰度、复杂公式和跨页条件仍影响解答质量。

默认自动启用当前已验证的 DeepSeek Flash 图像接口：

```text
PDF_VISUAL_MODE=auto
PDF_VISUAL_MAX_PAGES=3
PDF_VISUAL_MAX_EDGE=2000
```

其他视觉模型可显式使用 PDF_VISUAL_MODE=enabled；纯文字模型使用 disabled。服务商需要支持 Chat Completions 的 image_url 用户消息。

## 验证

公开验收摘要见 [本轮验证](evaluation-retrieval-vision.json)。使用独立临时数据和原创箭头图，分别验证：原样拒答的同轮恢复、真实规划的无资料解题、试卷 PDF 原图解答、教材 PDF 在默认阈值下的首轮解答。图中路径答案没有写进 PDF 文字层，期望结果为 P → T → Q → R。

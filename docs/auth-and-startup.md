# 登录、简洁工作台与启动优化

## 使用

运行 `scripts/start.ps1` 后打开 `http://127.0.0.1:8000`。首次使用从本机创建账号；用户名为 3–32 位字母、数字、下划线或短横线，忽略大小写，密码为 10–128 位。首个账号承接现有 `DATA_DIR` 中的课程、文件、索引和模型配置，无需移动或重新上传资料。远程首次注册返回 403，避免未完成初始化的旧资料被远程领取。

后续账号拥有独立课程、文件、错题、计划、对话、临时会话、向量索引和模型配置。登录后右上角账号菜单可以退出；会话默认有效七天，服务重启后继续有效，退出或过期后服务端拒绝业务访问。密码和会话令牌不存放在浏览器 localStorage。

首页保留资料提问和简明学习概况；新建课程、上传表单按需展开。题库、复习生成、错题计划、对话记录保留独立入口。已移除宣传插画、多色配色菜单、重复功能卡片和持续装饰动画。浅色、深色主题、手机资料抽屉、快捷操作和连续追问继续可用。

## 配置

| 配置 | 默认 | 用途 |
| --- | --- | --- |
| `AUTH_ENABLED` | `true` | 启用账号验证；`false` 为原有本地免登录模式 |
| `AUTH_REGISTRATION_ENABLED` | `true` | 首个账号创建后是否允许其他人注册 |
| `AUTH_COOKIE_SECURE` | `false` | HTTPS 部署设置为 `true`，本机 HTTP 保持 `false` |
| `AUTH_SESSION_HOURS` | `168` | 登录有效期，允许 1–720 小时 |

部署使用一个 Uvicorn worker：任务互斥、临时对话与请求计数仍是进程内状态。当前设计面向小规模单机多用户，未引入跨进程任务队列或集中式限流。HTTPS 反向代理应保留 Host 并正确传递协议，业务写操作按同源校验。

## 数据与鉴权

用户和可撤销会话存放在 `data/auth/users.db`。用户密码使用随机 16 字节盐和 scrypt（N=32768、r=8、p=3）；会话使用 256 位随机令牌，数据库只保存 SHA-256 摘要，Cookie 设置 HttpOnly、SameSite=Strict，Secure 由配置控制。注册和登录按进程内客户端地址限流，五分钟最多 15 次。首次账号判定采用 SQLite `BEGIN IMMEDIATE` 事务。

中间件验证所有 `/api/` 业务请求，并把该用户的服务对象放入 `request.state.services`。所有业务路由和后台上传任务引用这个空间，不修改全局 `app.state` 来切换用户。文件下载、课程删除、会话查询、生成导出等同样受隔离限制。鉴权路由和健康检查保持公开。

首个账号继续使用原 `DATA_DIR/studyagent.db`、`uploads/`、`chroma/`；其他账号使用 `DATA_DIR/users/<用户ID>/`。服务首次收到某账号的业务请求时才初始化该学习空间；后续请求复用数据库连接池和服务。新用户不继承服务器的 LLM 密钥，Embedding 仍使用服务器配置的检索服务，允许其使用统一检索后端。

## 启动性能

- 移除 Chroma 顶层导入，向量客户端及 collection 在第一次实际索引操作时初始化，使用锁保证并发只初始化一次；关闭未使用的索引不会触发加载。
- PDF、PPTX、DOCX 解析器按文件类型导入，OCR 模型继续按扫描页需求加载。
- HTTP 客户端、TLS 上下文和连接池首次调用模型服务时创建并复用；没有模型调用时不会初始化。
- 启动只初始化用户数据库；已有学习空间的恢复检查在该账号第一次访问时执行。索引指纹过期检查改为 SQL 批量更新，避免把全部资料对象加载到内存。

本机同一虚拟环境实测：改动前导入 `app.main` 15.797 秒；改动后 1.030 秒；改动后的隔离应用从导入到 `/health` 可响应共 1.207 秒，lifespan 115.1 毫秒。该测量为本机一次比较，未包含依赖安装；首次索引仍需支付 Chroma 初始化成本，首次模型请求仍需支付 TLS 初始化成本。

## 验证

完整 Python 回归 183 项通过；新增延迟 HTTP 测试及批量恢复/鉴权复测 10 项通过。真实 Edge 验证注册、上传、Agent 问答、题库练习、错题、计划、生成与下载、刷新恢复、退出、重新登录、会话失效、浅深色和减少动画，JavaScript 错误为 0。响应布局检查覆盖 320、375、390、768、1024、1440px。

独立验收脚本 `scripts/browser_minimal_auth.cjs` 只应运行于隔离演示服务，默认端口 8767；验收图片和 JSON 位于忽略的 `data/verify-minimal-auth/`。原有评估脚本显式使用本地免登录模式，其临时数据库和模型评估行为保持一致。真实外部模型质量未在本次界面/登录验收中重新评估。

实现参考：[Python scrypt 与密码派生](https://docs.python.org/3/library/hashlib.html#hashlib.scrypt)、[FastAPI lifespan](https://fastapi.tiangolo.com/advanced/events/)。

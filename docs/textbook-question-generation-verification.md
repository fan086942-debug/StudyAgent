# 教材自主出题：真实 API 运行验收

验收日期：2026-10-21。模型：本地已配置的 `deepseek-flash`；实际调用外部 API，未使用模拟模型响应。

结论：教材可检索后，可以先检索知识点正文，再交给 LLM 生成题目、参考答案和解析；每题保留引用编号，生成结果包含原资料知识片段及位置。上传教材本身不会自动生成题目，需要提交出题请求。

## 本次修复

默认本地字词向量检索对短知识点查询可能只召回章节标题，正文因相似度阈值被过滤。首次实测出现简答题拒绝生成，而其他题型虽生成成功，引用却只有标题。

`GenerationService._evidence` 改为复用已有 `Retriever.locate`：优先获取资料范围内的关键词原文命中，未命中时回退向量检索。无需降低全局相似度阈值。新增回归测试，确保正文不会因标题得分更高而遗漏。

所有成功用例同时验证了保存后读取、附答案 Markdown 下载及无答案卷下载。

真实 PDF 共 442 页，在独立学习空间复用原有、经文件指纹校验的 OCR 缓存，并通过正常重试接口重建 706 个索引片段；原文件、原数据库及原 OCR 缓存未修改。本次未重新执行整本扫描件 OCR，也未对这本 442 页教材执行全书逐章出卷。全章节出卷使用三章合成教材验证。

修复后的相关自动化测试：**67 passed**；修改文件的 Ruff 检查通过。存在两条上游依赖弃用警告。

## 可复现脚本与本地证据

仅合成教材：

```powershell
.\.venv\Scripts\python.exe -m scripts.verify_textbook_generation_api --skip-real-textbook
```

已获授权的现有教材测试（会向当前配置的模型服务发送相关教材片段并产生 API 用量）：

```powershell
.\.venv\Scripts\python.exe -m scripts.verify_textbook_generation_api --only-real-textbook --output data/textbook-real-api/report.json
```

- 合成教材报告：`data/textbook-generation-api/report.json`。
- 真实教材报告：`data/textbook-real-api/report.json`。
- 真实教材生成题目、答案、解析与原文片段：`data/textbook-real-api/real_pdf_topic.md`。
- 首次失败报告保存在上述目录各自的 `report-initial.json`。

报告及生成文件保存在已忽略的 `data/` 下，不包含 API 密钥。临时测试课程与索引在运行结束后清理。测试仅代表这些样本，不能据此推断所有知识点、OCR 公式及模型答案均正确。

## 使用

在学习 Agent 选择教材，输入“根据层次聚类出两道题目”，或“根据教材每章节重点为我出一套卷子，3道简答题”。生成后点击“预览生成结果”，可查看参考答案与解析，通过“查看这题的教材 / 课件依据”查看知识片段，也可下载包含来源原文快照的 Markdown。

API 可使用 `POST /api/agent`，传入 `course_id`、可选的 `document_ids` 和上述 `question`；题目详情与原文保存在回答所关联的 artifact 中。
